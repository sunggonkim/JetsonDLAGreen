# Configuration examples

This directory contains sanitized examples only.  Runtime-generated device
UUIDs and MPS paths are machine-local state and must not be committed.

`mig.env.example` documents the variables emitted by
`scripts/configure_thor_mig.sh`.  Copy it outside the repository or use the
default `/tmp/jdg-mps-1g/mig.env` path when running a campaign.
